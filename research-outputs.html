Research outputs

As of November 2026 I have reported 264 previously unknown bugs in 23 open-source RISC-V processors, and maintainers have confirmed 31 of them. Each one is a public GitHub or GitLab issue with a test case that reproduces it.

Most of these issues were filed anonymously for research purposes, so they do not appear under my name on GitHub or GitLab. For the complete list of reports, please email me at edwardazakov07@tamu.edu.

Bugs by processor

The cores range from small embedded designs to Linux-capable, superscalar, and out-of-order processors. Processor names link to each project's repository.

How the bugs were found

An LLM-guided formal verification framework (101), RVSentry, my library of formal security checks (126), and an extended ACT4 architecture test suite (37).

Where the bugs are

Most RVSentry and ACT4 findings sit in control and status registers, trap and interrupt handling, and memory protection.
